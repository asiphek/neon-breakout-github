# Neon Breakout
Neon breakout game in React + Vite. Home page, Play, Settings (volume + themes), Normal/Medium/Hard, score history, Clear Scores, zoomed-out laptop-friendly + mobile-friendly layout, ESC = Pause, boosters.
A friendly game created so you can have fun in your free time.
## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Boosters
WIDE, MULTI-BALL, SLOW, LASER (SPACE / SHOOT), SHIELD, EXTRA LIFE
